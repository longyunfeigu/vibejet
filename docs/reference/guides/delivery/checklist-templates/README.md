# Checklist Templates

Templates for each feature type. Use as starting point during Step 2 of the
[AI-Era Dev Workflow](../ai-era-dev-workflow.md).

| Type | Template | Use For |
|------|----------|---------|
| T1 | [t1-presentation.md](./t1-presentation.md) | UI/display-only changes |
| T2 | [t2-logic-extension.md](./t2-logic-extension.md) | Non-conflicting logic changes |
| T3 | [t3-conflicting-change.md](./t3-conflicting-change.md) | Changes that break existing assumptions |
| T4 | [t4-architectural-change.md](./t4-architectural-change.md) | Fundamental structure changes |
| T5 | [t5-cross-cutting.md](./t5-cross-cutting.md) | Changes across many modules |
| T6 | [t6-external-dependency.md](./t6-external-dependency.md) | Third-party library/service changes |

**Instructions**: Copy the relevant template, fill in the specific details, and tag each
item as `[AUTO]` or `[HUMAN]` according to the guidelines in
[checklist-generation-guide.md](../checklist-generation-guide.md).
