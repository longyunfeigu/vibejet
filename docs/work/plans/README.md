# Implementation Plans

No active implementation plans are currently tracked here.

Each plan is one file `{date}-{slug}.md` written by the `vj-plan` skill for human review: what and why,
key design (free-form, shaped by the work), decisions to make, acceptance checklist, and execution order
(only the last three have a fixed format). `vj-work` appends the acceptance-to-test mapping, the execution
log and acceptance notes. A whole-PRD input also gets a split overview `{date}-epic-0-overview.md`. Execution risk is expressed as
`policy: fast | strict` in the frontmatter.
