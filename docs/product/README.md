# Product Documentation

Product intent for an application built on top of the vibejet platform. No product is
currently tracked here; `vj-product-requirements` writes the PRD (`requirements.md`) into this
directory when one starts.

## Boundary

- 本目录只放**产品意图**：PRD、personas、launch 材料、产品侧研究。
- 平台事实与代码侧合同（`api/`、`data/`、`ui/`、`DESIGN.md`）住 `docs/project/`——合同跟随
  代码，不按 product/platform 拆分。
- 交付执行产物（Epic/Story、plan、task packets）住 `docs/work/`。
- UI 设计研究（mock board、screen inventory）按 vj 工作流的设计资产约定住
  `docs/reference/research/designs/`。
