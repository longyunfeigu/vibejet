# helpers

## 职责
共享测试工具,被 `modules/**/pages` 和 `modules/**/steps` 统一导入,避免重复代码。

## 内容

| 文件 | 说明 |
|------|------|
| `constants.ts` | 全局常量:测试数据前缀、会话存储键、超时、轮询间隔 |
| `wait-utils.ts` | 等待工具:等业务状态、等网络响应、带重试的导航(禁止固定毫秒等待) |

注意事项:
- 常量值不得硬编码在用例中,统一在 `constants.ts` 中定义后引用
- 测试数据的建/删不放这里,放 `core/api/entities/`
